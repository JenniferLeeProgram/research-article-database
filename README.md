# Research Article Database

A streamlined workflow for collecting and exploring research articles submitted by students.

## The Challenge

Students needed an easy way to contribute articles, while the instructor needed a consistent way to organize submissions and identify research trends across semesters.

## The Solution

This project uses Google Forms, Google Sheets, Google Apps Script, and Google Data Studio to support a connected research-library workflow.

- **Google Forms:** Guides students through article submissions.
- **Google Sheets:** Organizes entries in a shared database.
- **Google Apps Script:** Supports automated processing of submissions.
- **Google Data Studio:** Supports visual analysis of topics and trends.

## Instructional Design Approach

The project applies learner-centered design by simplifying data entry, using consistent categories, and making research information easier to explore.

## Technologies

Google Forms · Google Sheets · Google Apps Script · JavaScript · Google Data Studio

## Project Status

Prototype in development. Features and dashboard access will be updated as the project is tested and refined.
